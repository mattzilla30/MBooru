# MBooru 7

Android version code: 1380. Package: `com.mattzilla30.mbooru`. Minimum API 21; target API 36. Updates retain the existing signing identity and application data.

- Explore, Search, Saved, Sites and Settings are the primary tabs. Existing engine-specific tools remain in More and the drawer.
- Rule34 has a dedicated HTTPS adapter and encrypted account connection. Search supports explicit/debounced submission, ratings, exclusions and supported sorting, with cancellable paging and restored per-site state.
- One local library holds saves, likes and named collections across sites. These actions are distinct from supported remote favorites.
- Versioned, credential-free library export/import includes preview and atomic merging. M34 users can export through the companion M34 2 update and import the resulting document.
- The existing tiled image viewer and Media3 playback are retained. Downloads add quality selection, configurable size limits and active-transfer deduplication across temporary document IDs.
- Fixes Android 5 crashes from failed favicon rendering and preserves cached search position/page boundaries across tab returns and activity recreation.
- Optional device-credential app lock is available in Settings. BGSU colors, MBooru branding and existing project credits remain.

Schema 12 migrates existing saves without destructive fallback. See [integration instructions](../integration/m34.md) and [validation evidence and remaining checks](../validation/m34-integration.md).

This is a reviewable release candidate. Live Rule34 account access, physical ARM64 behavior, full SAF transfer and hardware performance require the remaining checks described in the validation report.
