# MBooru 16

Android version code: 1389.

- Replaces the legacy open-source license viewer with an MBooru screen using the app's BGSU colors and light/dark theme.
- Adds a searchable, scrolling dependency list, selectable license text, and consistent toolbar/system Back navigation. Opening a license dismisses the search keyboard; the open license and search survive activity recreation.
- Reads the OSS plugin's bundled UTF-8 byte ranges and preserves multiple licenses for a dependency. Common Apache license URLs show the bundled complete Apache 2.0 text offline.
- Includes the existing MBooru/Flexbooru, Boorusphere, AndroidX Preference and PhotoView notices. Other bundled license text and URL-only notices remain available.

The OSS plugin intentionally includes a placeholder catalog in debug APKs; release APKs contain the full generated dependency catalog. No network connection or Google license-viewer activity is needed to read bundled notices.
