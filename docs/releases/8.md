# MBooru 8

Android version code: 1381. Package: `com.mattzilla30.mbooru`. Minimum API 21; target API 36.

- Bottom navigation contains Explore, Search and Saved.
- Open Settings from More or the drawer. Sites is a Settings entry, with Back returning to Settings after managing sites.
- The compact toolbar omits the current booru name. Duplicate Explore/Search/Saved headings are removed, bringing controls and media closer to the top. Toolbar controls use the current theme's foreground colors.
- Sites, App lock, Maximum download size and all existing preferences share one scrolling settings list.

Navigation regression checks cover the toolbar-to-search spacing, three-tab layout, Settings/Sites access and back navigation, scrolling both formerly pinned settings out of view, and preserving search across recreation.

Validation in the cloud workspace: 127 Android unit/Robolectric tests and 5 core tests passed, with no failures, errors or skips. Static analysis, Android lint and Android test-APK compilation passed. Native emulator and physical-device tests for this layout change have not been executed locally; the PR's API 21/28/36 workflow runs separately.
