# MBooru 9

Android version code: 1382. Package and signing identity are unchanged.

- The main search field contains the three-dot menu alongside Clear.
- The hamburger button, More label and separate toolbar row are removed from Explore and Search, without reserving their previous space.
- Advanced browsing is removed from the menu. Restored navigation or a Posts destination opens the main search workspace instead of the old posts layout and its lower search panel.
- Settings and site switching remain in the three-dot menu. Tools opens the existing drawer for other supported browsing tools.
- Explore, Search and Saved remain the bottom tabs; Sites and all scrolling preferences remain in Settings.
