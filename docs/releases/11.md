# MBooru 11

Android version code: 1384. The existing package, signing identity and Favorites library are retained.

- The viewer no longer shows the Add to favorites, Like locally or Collections text actions. Its existing favorite button remains functional, with per-post state tracking retained. The viewer control strip is shorter.
- The primary search screen no longer has heart or Settings icons, or a reserved header row on secondary pages. Favorites and Settings remain available from the side panel.
- The default browsing header consists of one search field and one compact controls row. Search submits through the field's search icon or keyboard; Clear appears when text is present.
- Filters, sorting, applied-tag chips and discovery-tag controls expand on request instead of occupying media space by default. Autocomplete remains available while editing.
- System-bar safe areas, grid position restoration and the absence of bottom navigation/search panels are preserved.
