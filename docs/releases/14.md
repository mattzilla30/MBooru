# MBooru 14

Android version code: 1387.

- The side panel no longer includes Add new server or Explore this server. Server management remains in Settings → Servers → Sites.
- Supported Posts, Popular, Pools, Tags and Artists options appear in the horizontally scrolling controls row below the search field, alongside Filters and Refresh. Popular appears once.
- Secondary browsing pages expose the same supported options in their top controls, allowing direct switching between tools.
- Posts returns to the primary search workspace; other tools retain their existing navigation, query restoration and reselect-to-scroll behavior.

No bottom navigation, lower search panel or overflow menu is added.
